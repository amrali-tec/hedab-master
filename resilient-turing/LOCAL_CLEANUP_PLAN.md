# HEDABKH LOCAL WORKSPACE CLEANUP PLAN

## Overview
This plan establishes ONE authoritative source of truth for the local HEDABKH project (`F:\resilient-turing`) by auditing all existing files, classifying them, and safely removing obsolete static exports, duplicate directories, old deployment archives, and stale build caches.
